# Задание 27. Сочинение ЕГЭ

## Структура сочинения

| № | Пункт | Содержание | Речевые шаблоны |
|---|-------|------------|-----------------|
| 1 | **Проблема** | Проблема сформулирована в задании | *«Вот проблема текста <имя автора>»*; *«<Имя автора> в предложенном для анализа тексте размышляет о/над…»*; *«Ответ на этот вопрос <имя автора> даёт в предложенном для анализа тексте»* |
| 2 | **Авторская позиция** | Авторская позиция (= идея текста, то есть зачем автор написал текст) + ответ на вопрос проблемы | *«Автор считает, что…»*; *«По мнению автора,…»* |
| 3 | **Комментарий** | Два примера с пояснением (вывод из текста, являющийся ответом на вопрос проблемы) и связь между примерами с пояснением | *«Примеры дополняют друг друга»*; *«Однако в тексте представлена и другая точка зрения»*; в связке дополнения обязательно *"не только ..., но и..."* |
| 4 | **Личная позиция + аргументация** | Личная позиция + аргументация личной позиции. **Не зеркалить текст!** + доказательство тезиса одним примером | *«Я согласен с авторской позицией и считаю, что <тезис>»* |
| 5 | **Вывод** | Можно не писать, если мысль завершена | — |

Подробная таблица (на примере сочинения о роли старых вещей):

|         Раздел        | Текст                                                                                                                                                               |
|:---------------------:|---------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|        Проблема       | Какую роль играют старые вещи? Вот проблема, которая поднимается в тексте Татьяны Толстой                                                                           |
|   Авторская позиция   | Авторская позиция ясна: ...                                                                                                                                         |
|        Пример 1       | Пересказ или цитата текста                                                                                                                                          |
| Пояснение к примеру 1 | Мы понимаем: *что мы понимаем из приведенного примера*                                                                                                              |
|        Пример 2       | Опять пересказ или цитата                                                                                                                                           |
| Пояснение к примеру 2 | Мы видим: *что мы видим из второго примера*                                                                                                                         |
| Связь между примерами | Примеры дополняют *(или еще какая-либо связка)* друг друга...                                                                                                       |
|    Пояснение связи    | ...и показывают, что ... не только ..., но и ... *(пример для связки дополнение)*                                                                                   |
|      Моя позиция      | Я согласен/не согласен с авторской позицией и считаю, что...                                                                                                        |
|        Аргумент       | Аргументация жизненным, литературным, историческим опытом                                                                                                           |
|         Вывод         | *опционально, можно совместить с аргументом                                                                                                                         |

## Переходы

| Переход | Варианты |
|---------|----------|
| **1 → 2** | *«Для подтверждения авторской позиции обратимся к тексту»*; *«Проследим, как эта мысль раскрывается в тексте»* |
| **3 (между примерами)** | *«Далее автор пишет о том, что…»*; *«Однако в тексте представлена и другая точка зрения»* |
| **3 (между примерами и пояснением)** | *«Становится понятно, что…»*; *«Читатель осознаёт, что…»*; *«Писатель акцентирует внимание на то, как/что…»* |
