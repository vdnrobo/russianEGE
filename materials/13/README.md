# Задание 13. Правописание НЕ и НИ с разными частями речи

## 1. НЕ с разными частями речи: общее правило

Если слово без НЕ не употребляется, НЕ пишется слитно независимо от части речи.

| Слитно                        | Примеры                                                                 |
| ----------------------------- | ----------------------------------------------------------------------- |
| Слово без НЕ не употребляется | недоумевать, ненавидеть, негодовать, невежа, невежда, нелепый, небрежно |

## 2. НЕ с глаголами и деепричастиями

| Слитно                                                                                 | Раздельно                                                                          |
| -------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| Если слово без НЕ не употребляется: ненавидеть, недоумевать, негодовать, нездоровиться | В остальных случаях: не знать, не думать, не пришёл, не сделав, не спеша, не глядя |
| Если НЕДО- означает недостаточность действия: недосыпать, недооценивать                | Если НЕ отрицает действие: не досыпать сахар, не доедать обед                      |

Как отличить глагол от деепричастия?

- Глагол: что делать? что сделать? — не читать, не решить.
- Деепричастие: что делая? что сделав? — не читая, не решив.

## 3. НЕ с существительными, прилагательными и наречиями на -О/-Е

| Слитно                                                                                                                | Раздельно                                                                                                       |
| --------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Можно заменить синонимом без НЕ: неправда (= ложь), недруг (= враг), нескучный (= интересный), невысоко (= низко)     | Есть противопоставление с союзом А: не высокий, а низкий; не правда, а ложь                                     |
| Слово без НЕ не употребляется: нелепость, невежливый, небрежно                                                        | Есть слова-магниты: вовсе не, далеко не, отнюдь не: вовсе не интересный, далеко не простой                      |
| Есть слова меры и степени: очень, весьма, крайне, чрезвычайно, абсолютно, слишком: очень некрасивый, весьма непростой | Есть усиление отрицания: ничуть не, нисколько не, никому не, никогда не: ничуть не смешной, нисколько не трудно |

Обрати внимание на союз НО:

- Недорогой, но красивый — слитно: союз НО не создаёт противопоставления с отрицанием.
- Не дорогой, а дешёвый — раздельно: есть противопоставление с А.

## 4. НЕ с прилагательными: особые случаи

### Относительные и притяжательные прилагательные

| Слитно                                                                              | Раздельно                                                               |
| ----------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| Если прилагательное качественное и выполняются общие условия: некрасивый, невысокий | С относительными прилагательными: стол не деревянный, юбка не шерстяная |
|                                                                                     | С притяжательными прилагательными: платье не мамино, галстук не папин   |

### Прилагательные с суффиксом -ИМ-

| Слитно                                                                                                                      | Раздельно                                                                                           |
| --------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| При соблюдении общих условий: неувядаемый, неиссякаемый, непреодолимый, непобедимый, неукротимый, несокрушимый, необитаемый | При противопоставлении или зависимых словах, требующих раздельного написания: не любимый мной автор |

Важно: наличие суффикса -ИМ- само по себе не гарантирует слитного написания.

## 5. НЕ с краткими прилагательными

| Слитно                                                                             | Раздельно                                                                                                                         |
| ---------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| По общим правилам, как и с полными прилагательными: ответ неверен, задача несложна | Слова, которые нужно запомнить: не рад, не должен, не обязан, не намерен, не прав, не готов, не согласен, не способен, не склонен |
|                                                                                    | При противопоставлении: ответ не верен, а ошибочен                                                                                |

## 6. НЕ с причастиями

| Слитно                                                                                             | Раздельно                                                                      |
| -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| Полное причастие без зависимых слов: непрочитанная книга, нерешённая задача, невыполненное задание | Есть зависимые слова: не прочитанная мной книга, не решённая учеником задача   |
|                                                                                                    | Есть противопоставление с А: не решённая, а только начатая задача              |
|                                                                                                    | Краткие причастия: работа не выполнена, письмо не отправлено, задача не решена |

Как отличить причастие от прилагательного?

| Прилагательное                                        | Причастие                                                           |
| ----------------------------------------------------- | ------------------------------------------------------------------- |
| Обозначает признак или качество                       | Обозначает признак по действию                                      |
| Девочка невоспитанна — характеризуется как невежливая | Девочка не воспитана родителями — говорится о результате воспитания |

## 7. НЕ и НИ с местоимениями и местоименными наречиями

### Отрицательные местоимения и наречия

| Слитно                                                             | Раздельно                                                       |
| ------------------------------------------------------------------ | --------------------------------------------------------------- |
| Без предлога: некого, нечего, никто, ничто, негде, некуда, некогда | С предлогом: не у кого, не с кем, не о чем, ни у кого, ни с кем |

Как различать НЕ и НИ?

| НЕ — под ударением                        | НИ — без ударения                        |
| ----------------------------------------- | ---------------------------------------- |
| нЕкого спросить, нЕчего сказать, некогдА? | никто́ не пришёл, ни у кого́ не спросить |

Ударение помогает различать формы, но ориентироваться нужно также на значение и грамматическую конструкцию.

### Остальные местоимения

| Слитно                                                               | Раздельно                                                                     |
| -------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Отрицательные местоимения без предлога: никто, ничто, некого, нечего | Другие местоимения: не я, не ты, не каждый, не всякий, не тот, не мой, не сам |

## 8. НЕ КТО ИНОЙ, КАК и НИЧТО ИНОЕ

| Раздельно: НЕ КТО ИНОЙ, КАК                                                                       | Слитно: НИКТО ИНОЙ                                                      |
| ------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| При указании на конкретное лицо или предмет с конструкцией КАК: Это был не кто иной, как мой брат | При отрицании, без конструкции КАК: Никто иной не смог бы этого сделать |
| Это не что иное, как ошибка                                                                       | Ничто иное меня не интересовало                                         |

## 9. Что стоит запомнить

| Выражение                          | Правильное написание   |
| ---------------------------------- | ---------------------- |
| Чувствовать себя плохо             | нездоровится           |
| Почувствовать себя плохо в будущем | не поздоровится        |
| Делать что-то без желания          | нехотя                 |
| Делать что-то не торопясь          | не спеша               |
| Несмотря на обстоятельства         | несмотря на трудности  |
| Не направляя взгляд                | не смотря по сторонам  |
| При любых обстоятельствах          | во что бы то ни стало  |
| Как будто ничего не произошло      | как ни в чём не бывало |

Главное: сначала определи часть речи, затем проверь зависимые слова, противопоставление, слова-усилители и возможность замены синонимом. Это поможет выбрать между слитным и раздельным написанием.
