# Задание 18. Вводные слова

## 1. «Чистенькие» (всегда вводные слова)

| Группа по значению | Примеры слов |
| :--- | :--- |
| **Порядок мыслей** | *во-первых, во-вторых, в-третьих, итак, значит (в знач. "следовательно"), наконец (в знач. "и еще")* |
| **Степень уверенности** | *вероятно, безусловно, конечно, разумеется, несомненно, очевидно, возможно, видимо* |
| **Чувства и эмоции** | *к счастью, к несчастью, к удивлению, к сожалению, на беду, странное дело* |
| **Источник информации** | *по-моему, по-вашему, говорят, как известно, по слухам, дескать* |

---

## 2. «Хамелеоны» (вводные / не вводные — зависит от контекста)

| Слово | Вводное (запятая нужна) | Не вводное (запятая НЕ нужна) |
| :--- | :--- | :--- |
| **кажется** | *Кажется*, он уже ушел. (оценка) | Небо *кажется* синим. (глагол "казаться") |
| **таким образом** | *Таким образом*, мы решили проблему. (= итак) | Мы шли *таким образом* (каким? — указание на способ) |
| **значит** | Ты болен, *значит*, останешься дома. (= следовательно) | Это *значит* многое для меня. (глагол) |
| **может (быть)** | *Может быть*, дождь пройдет. (= возможно) | Он *может* прийти поздно. (глагол + инфинитив) |

---

## 3. «Ваще никогда» (никогда не вводные)

| Тип слова | Примеры |
| :--- | :--- |
| **Частицы сомнения** | *вряд ли, навряд ли, едва ли, чуть ли* |
| **Усилительные частицы** | *даже, именно, как раз, ведь, всё-таки* |
| **Союзы и союзные обороты** | *тем не менее, несмотря на то что, якобы, к тому же, при этом, между тем* |
| **Обстоятельства** | *в конце концов, по крайней мере* |

---

## 4. «Особые случаи» (детальный разбор)

### Действительно

| Случай | Правило | Пример |
| :--- | :--- | :--- |
| **Вводное** | = «да, это так», «согласен». Выражает согласие. | Он, *действительно*, гений. |
| **Не вводное** | = «на самом деле», «в реальности». Обстоятельство. | Он *действительно* пришел вовремя. |

### Наконец

| Случай | Правило | Пример |
| :--- | :--- | :--- |
| **Вводное** | = «и еще» (перечисление), выражает нетерпение. | Во-первых, он умен, *наконец*, он опытен. |
| **Не вводное** | = «под конец», «после долгого времени» (обстоятельство). | Мы долго бродили и *наконец* вышли к реке. |

### Однако

| Случай | Правило | Пример |
| :--- | :--- | :--- |
| **Вводное** | Стоит в середине или конце, = «но» (междометие). | Он, *однако*, опоздал. (запятые с двух сторон) |
| **Союз (НЕ вводное)** | Стоит в начале предложения, = «но». | *Однако* дождь закончился. (запятую после НЕ ставим) |
| **Союз (НЕ вводное)** | Связывает однородные члены. | Он устал, *однако* не сдавался. |
